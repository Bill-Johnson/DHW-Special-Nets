Code won't open?

  • A code is a spooky word plus one number, like BAT7. The number is always 2 to 9, so an O is a letter, never a zero.
  • Capital letters and spaces don't matter.
  • Check your copy against the check-in readback. If a character got garbled, ask on the air for a fill. That's what nets are for.
